# BlueRay Wealth - Mutual Fund Guidance and Investor Education

A modern, responsive, and bilingual investor education website and lead-generation portal built for **Suresh Saini**, AMFI Registered Mutual Fund Distributor (**ARN: 347947**), based in Jaipur, Rajasthan, serving investors across India with **NJ Wealth** as the institutional platform partner. Tagline: *Trust • Guidance • Growth*.

## Key Features
- Multi-Tier Life Goal and Financial Calculators (Retirement, Child Education, Child Marriage, Milestone Goal, SIP, Lump-Sum, SIP vs FD, Cost of Delay, Inflation Estimator)
- Bilingual Experience (English and Hindi)
- Responsive Light and Dark Theme
- Regulatory compliance with AMFI ARN 347947 and NJ Wealth partner transparency

## Live Website on GitHub Pages
1. Push this repository to GitHub.
2. Go to Settings > Pages.
3. Select Branch: main, Folder: / (root).
4. Click Save. Your website will be live at: https://<username>.github.io/<repo-name>/
